# Skill: C语言代码修改与创建追踪

## 触发条件
当用户要求你创建新代码、修改现有代码或重构 C 语言代码时，触发此技能。

## 执行流程

### 1. 改动前：声明修改者（必须）
在开始编写或修改任何代码之前，你必须检查当前会话中是否已经明确了“修改者名称”。
- 如果未明确，你必须**停止生成代码**，并向用户提问：“为了规范代码版本，请在开始修改前告诉我本次的修改者名称是？”
- 只有在用户回复了修改者名称后，才能进入下一步。

### 2. 改动时：添加注释标记
在生成代码时，你必须在所有被修改或新建的代码块上方，严格使用 `format_template.c` 文件中定义的 C 语言块注释格式进行标注。
- `Change` 只能是 `新增` 或 `修改`。
- `Time` 需获取当前日期，格式为 YYYY-MM-DD。

### 3. 输出说明
代码生成完毕后，用简短的文字总结本次修改涉及了哪些位置，以方便用户核对。
