# ResistorTactileBoard 固件项目文档

## 项目概述

**项目名称**：ResistorTactileBoard_Firmware（压阻数采板固件）

**主要功能**：32×32压阻触觉矩阵数据采集系统，用于实时读取压阻传感器阵列的电阻变化，实现触觉感知功能。

**硬件平台**：STM32F103C8T6（Cortex-M3, 72MHz, 64KB Flash, 20KB SRAM）

**操作系统**：RT-Thread Nano（实时操作系统）

**开发工具**：STM32CubeMX + CMake + GCC

└─────────────────────────────────────────────────────┘
┌─────────────────────────────────────────────────────┐
│                   驱动层 (BSP Drivers)                │
├─────────────────────────────────────────────────────┤

项目采用模块化设计，通过 `bsp_config.h` 集中管理所有BSP模块的启用开关：

- **BSP_USE_STATUS_LED**：状态LED模块

- **BSP_USE_ADS8681**：ADC模块
- **BSP_USE_CD74HC4067_MUX**：列选择模块
- **BSP_USE_BASIC_SERVICE**：基础服务模块
- **BSP_USE_PRODUCT**：产品序列号模块

### 2.2 SPI外设配置

#### SPI1（ADS8681 ADC通信）
- **模式**：主模式，全双工
- **数据帧**：8位，MSB先出
- **时钟极性**：CPOL=0, CPHA=0
- **波特率**：APB2(72MHz)/32 = 2.25MHz
- **DMA**：RX通道 (DMA1_Channel2)

#### SPI2（74HC595行驱动）
- **模式**：主模式，单工发送
- **数据帧**：8位，MSB先出
- **时钟极性**：CPOL=0, CPHA=0
- **波特率**：APB1(36MHz)/32 = 1.125MHz

### 2.3 定时器配置

#### TIM2（数据采集时基）
- **预分频**：71 (72MHz/72 = 1MHz计数频率)
- **自动重装值**：99 (1MHz/100 = 10kHz，100µs周期)
- **中断优先级**：0（最高）

## 3. 软件逻辑

### 3.1 数据采集流程

系统采用全中断驱动架构（方案B：零CPU占用采样）：

```
TIM2 ISR (100µs周期)
    │
    ├─ 行首: 74HC595切换行激励 + 死区延时
    ├─ CD74HC4067列选通
    └─ CS↓ + 启动SPI1 TX+RX DMA
        │
        ▼
SPI1 DMA完成ISR (~14µs后)
    │
    ├─ CS↑（触发ADS8681下次转换）
    ├─ 提取16-bit结果 → frame[row*32+col]
    └─ 推进状态机 (col++ / row++ / 帧完成信号量)
        │
        ▼
扫描线程 (每帧醒一次, ~105ms)
    │
    ├─ frame_pool_get() → 获取空帧
    ├─ 启动扫描 (scanning=1)
    ├─ sem_take(frame_done) → 阻塞等帧完成
    └─ rt_mb_send(frame) → 投递给USB线程
```

### 3.2 时序分析

- **每行时序**：1 tick丢弃（清除旧行陈旧数据）+ 32 tick有效读取 = 33 tick
- **每帧时间**：32行 × 33 tick × 100µs = 105.6 ms
- **理论帧率**：~9.5 fps

### 3.3 线程模型

| 线程 | 优先级 | 栈大小 | 功能 |
|------|--------|--------|------|
| main | 10 | - | 主线程，系统初始化 |
| data_acq | 5 | 1024B | 数据采集线程 |
| usb_cdc | 15 | - | USB CDC发送线程 |
| idle | 31 | - | 空闲线程 |

### 3.4 IPC机制

- **邮箱 (frame_mb)**：采集线程 → USB线程，传递帧缓冲指针
- **信号量 (frame_pool_sem)**：帧缓冲池同步
- **信号量 (frame_done_sem)**：帧完成通知

## 8. 启动流程

### 8.1 启动链

```
上电/复位
    │
    ▼
Reset_Handler
    │
    ▼
entry() (RT-Thread入口)
    │
    ▼
rtthread_startup()
    │
    ├─ rt_hw_board_init()
    │   ├─ HAL_Init()
    │   ├─ SystemClock_Config()
    │   ├─ 外设初始化 (GPIO/DMA/SPI/UART/TIM/USB)
    │   └─ 基础服务初始化
    │
    ├─ 调度器初始化
    │
    └─ 创建主线程 → main()
```

### 8.2 主函数流程

```c
int main(void) {
    bsp_init();                    // BSP驱动初始化
    bsp_basic_service_init();      // UART控制台
    bsp_frame_pool_init(32, 32);   // 帧缓冲池
    USB_CDC_app_Init();            // USB CDC应用
    DATA_ACQUISITION_DEBUG_Init(); // 调试命令
    params_init();                 // 系统参数
    
    while(1) {
        rt_thread_mdelay(100);
    }
}
```

## 11. 扩展性

- 支持不同矩阵规模（通过修改SCAN_ROWS/SCAN_COLS）
- 支持不同ADC型号（通过修改ADS8681驱动）
- 支持不同行驱动方案（通过修改74HC595驱动）

### 11.2 软件扩展

- 模块化设计，易于添加新功能

- Flash参数存储，支持运行时配置

## 12. 注意事项

### 12.1 硬件注意事项

- ADC输入范围需根据传感器特性配置
- 行驱动电流需满足传感器需求
- 电源稳定性影响采样精度

### 12.2 软件注意事项

- 中断优先级配置需合理，避免数据丢失
- 帧缓冲池大小需根据系统内存调整
- USB传输需考虑带宽限制
